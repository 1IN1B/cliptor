Cliptor

macOS Menu Bar Clipboard History Utility

Never lose a copy again. Cliptor lives in your menu bar, silently monitors your clipboard, and keeps a searchable history of everything you copy. Browse, search, and auto-paste with keyboard shortcuts.

Get Started Learn More

Everything at your fingertips

Cliptor turns your clipboard into a powerful, searchable database.

Auto-capture

Monitors your clipboard every 800ms. Every piece of text you copy is automatically saved — no manual action needed.

Instant search

Start typing to filter through your entire history in real time. Find that link you copied hours ago in milliseconds.

⌘1 – ⌘9 shortcuts

Press Command plus a number to instantly copy and paste any of the last 9 items. No mouse, no menu navigation.

Auto-paste

Click an item and Cliptor automatically pastes it into your previous app via Cmd+V simulation. Seamless workflow.

Link previews

Paste a URL and Cliptor fetches the page title, description, and OG image — so you always know what that link is.

Persistent history

Up to 50 items saved to disk. Close the app, restart your Mac — your clipboard history is still there when you come back.

Get started in seconds

Clone, install, and run. No build tools, no complex setup.

1

Clone the repo

git clone https://github.com/anomalyco/cliptor.git
2

Install dependencies

cd cliptor && npm install
3

Launch Cliptor

npm start

For development with hot reload, use npm run dev instead.
